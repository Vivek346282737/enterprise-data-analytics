# Excel Analytics Workbook: `analytics_dashboard.xlsx`

Generated by `python/reporting/excel_builder.py` (run `python run_pipeline.py`). Analysis sheets contain **live formulas**,
not pasted numbers. Change the yellow input cells and everything recalculates.

| Sheet | What it shows | Excel features |
|---|---|---|
| Executive_Report | KPI cards, top region/category/return reason, charts | cell links, INDEX/MATCH + MAX, line & bar charts |
| Raw_Data | products.csv as received (defects visible) | Excel Table, COUNTBLANK, COUNTIF wildcard, SUMPRODUCT distinct count, conditional formatting for blanks |
| Cleaned_Data | monthly sales cube (month × region × channel × category) | Excel Table `tblSales`, calculated columns: profit, IFERROR margin, YEAR, ROUNDUP(MONTH/3) quarter, TEXT month |
| Data_Quality | DQ score raw vs clean, issue log | IFS status, colour scales, data bars, COUNTIFS, bar chart |
| KPI_Summary | headline KPIs, all years and selected year | SUM, SUMIFS, IFERROR, IFS, **data-validation dropdown** (year), Python cross-check with IF/ABS |
| Sales_Analysis | monthly revenue/profit, MoM, YoY, running, rolling 3M/12M | DATE, SUMIFS, relative/absolute references, conditional font colours, line chart |
| Customer_Analysis | 8.8k customers with RFM; lookup panel; segment summary | **XLOOKUP**, **INDEX/MATCH**, RANK.EQ, COUNTIFS, SUMIFS, AVERAGEIFS, DATE arithmetic, dropdown, data bars, pie chart |
| Product_Analysis | product margin, return rate, rank, tier, Pareto | RANK.EQ, IFS, cumulative SUM, colour scale, data bars, highlight rule |
| Regional_Analysis | zone and channel performance | SUMIFS, nested IF, colour scales, bar chart |
| Returns_Analysis | returns register + reason/category summaries | COUNTIFS, SUMIFS, IF flag, conditional formatting, bar chart |
| Pivot_Analysis | category × year and region × channel cross-tabs | SUMIFS cross-tab, CAGR, heat-map formatting, clustered column chart |

**Note on XLOOKUP:** needs Excel 2021 / Microsoft 365. The INDEX/MATCH cells beside it give the same result in older versions.

## Native PivotTable + PivotChart (1 minute, manual)
The Python library used (openpyxl) cannot create native PivotTables, so the Pivot_Analysis sheet uses formula cross-tabs.
To add a real PivotTable:
1. Click any cell in `Cleaned_Data` → **Insert → PivotTable** → Table/Range: `tblSales` → New worksheet.
2. Rows: `category`; Columns: `year`; Values: `Sum of revenue`, `Sum of profit`.
3. **PivotTable Analyze → PivotChart → Clustered Column**. Add slicers for `region_name` and `channel_name`.

## Power Query workflow (Get & Transform)
The same cleaning can be reproduced in Excel's Power Query on the raw files:
1. **Data → Get Data → From File → From Folder** → `data/raw` → *Combine & Transform* is not needed; load each CSV separately.
2. `products`: *Transform → Format → Trim* and *Clean* on text columns → *Replace Values* `₹` and `,` with nothing on
   `unit_price` → change type to Decimal → *Add Column → Conditional Column* to map category variants
   (e.g. `if Text.Lower([category]) = "electronic" then "Electronics" ...`) or merge with a mapping table.
3. `customers`: Trim/Proper case names, lower-case email → *Remove Duplicates* on all columns → *Group By* lower(email) to
   find duplicate accounts → keep the earliest `signup_date`.
4. `orders`: change `order_date` type with *Using Locale* to catch dd/mm/yyyy, *Replace Errors* with null, then
   *Merge Queries* with `payments` (order_id) to fill missing dates from `payment_date`.
5. `order_items`: Remove duplicates, filter quantity 1-50, add custom column `[line_amount] ?? [quantity]*[unit_price]*(1-[discount_pct])`.
6. *Merge* into a sales query, *Group By* month/region/channel/category → *Close & Load To…* Table → this becomes `Cleaned_Data`.
7. *Data → Refresh All* re-runs every step when new raw files arrive (automation).
The equivalent M code for the mart load is in `powerbi/power_query.m`.
